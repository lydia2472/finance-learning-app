# 每日金融一课 📚

从金融小白到投资能手的完整学习系统。

## 功能

- **175 课完整课程**：主线 7 阶段（理财启蒙 → 个人财务 → 保险保障 → 投资工具 → 基金实战 → 宏观与行为金融 → 长期财富管理）+ 进阶选修（CFA Level I 小白版）
- **互动测验**：每课 3 道题，即时反馈与解析
- **学习进度追踪**：打卡连胜、阶段进度、收藏功能
- **CFA 进阶中心**：知识地图、备考进度追踪、报考实务
- **每日财经简报**：五分类新闻 + 「为什么和你的钱包有关」解读 + 关联课程链接
- **持仓工具**：资产分布诊断、历史风险参考（Wind 数据）、情景推演（非预测）
- **AI 助教**：基于课程内容的智能问答（本地 Ollama / OpenAI 兼容 API）

## 快速开始

```bash
# 安装依赖（需要 Node 18.18+）
npm install

# 开发模式
npm run dev

# 生产构建
npm run build
npm start
```

## 启用 AI 助教（可选）

安装 [Ollama](https://ollama.com) 并拉取模型：

```bash
brew install ollama
brew services start ollama
ollama pull qwen2.5:7b
```

默认配置已指向本地 Ollama，无需额外设置。
